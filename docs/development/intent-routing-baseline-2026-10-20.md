# 意图路由耗时基线（2026-10-20）

## 测量范围

在本机现有 `127.0.0.1:8090` Halo 测试站，通过匿名 `POST /apis/api.ai-suite.halo.run/v1alpha1/chat` 逐条发送问题。每个问题只测一次；只记录 HTTP 状态、端到端耗时和结构化文章数量，没有保存回答正文或请求凭据。该站尚未安装草稿 PR #25 的分类空输出补丁，因此这些数据仅用于选择后续优化方向，不能作为新版本性能结论。

| 问题 | 耗时 | 文章数 |
| --- | ---: | ---: |
| 最近有哪些 AI 文章？ | 3.38 秒 | 4 |
| 最近有哪些 DeepSeek 文章？ | 3.26 秒 | 1 |
| 最近有哪些旅游日记？ | 1.78 秒 | 10 |
| 哪些文章最热门？ | 0.02 秒 | 10 |

前三个问题触发的“最新文章”路由包含 `TOPIC_MATCH` 模型判断；“热门文章”路由仅按访问量排序。这组数据说明分类模型调用值得优先测量，但不同问题和路由不能直接作为严格的同条件性能对照。

## 本轮决定

先提供可选的意图路由语言模型配置，留空时维持对话模型回退。当前站点文章量不大，贸然在模型调用前缩减文章集合有漏掉相关文章的风险；候选预筛选须准备有标注的问句和文章集合，比较召回率、准确率、模型输入量及 P50/P95 延迟后再实施。

独立模型配置只接受 Halo AI Foundation 中可用的语言模型资源。其他独立决策 API 需单独适配，不能只填写一个模型名称来代替当前语言模型调用。
