# 0.4.2 安装与升级验收

验收日期：2026-10-13。目标制品为本地构建的 `plugin-ai-suite-0.4.2.jar`，SHA-256：`dee1309fce710e8506774b5b8e3615f7f298e9ea2a043c3fe4438bbeadea658d`。升级起点为 GitHub Release `v0.4.1` 的正式 JAR，SHA-256：`0345749c61f5844ae05c198fc82df699df135f21197d9eff8c9edef8ae67cb11`，与该 Release 公布的摘要一致。

## 环境

- 两套相互独立的临时 Halo 2.26.1 站点，均使用全新 H2 数据目录。
- 两套站点均将预置 AI Foundation 1.0.0 升至官方发布的 1.1.1，再安装 AI 智能套件；AI Foundation 1.1.1 JAR 的 SHA-256 与官方 Release 一致。
- 未连接模型供应商；本轮仅验证安装、升级、配置和内容数据连续性。真实标签生成与应用已在原开发站点的测试文章上另行验证。

## 全新安装

1. 上传 0.4.2 JAR 后，Halo 识别插件 ID 为 `ai-suite`，版本为 `0.4.2`。
2. 启用后 `status.phase` 为 `STARTED`，`Ready` 条件为 `TRUE`。
3. Console「内容创作」下出现「AI 标签」入口；页面可加载模型说明、使用说明和文章列表，默认文章「Hello Halo」及其既有「Halo」标签正常显示。

## 从 0.4.1 升级

1. 在第二套全新站点安装并启用正式发布的 0.4.1 JAR，确认 `status.phase=STARTED`。
2. 将模型配置中的向量维度从默认 `1024` 保存为 `768`，记录 `ai-suite-configmap` 的全部 `data`，以及文章名称、标题和标签引用。
3. 通过 Halo 插件升级接口上传 0.4.2 JAR，确认插件版本变为 `0.4.2`，启用状态保持为 `true`，`status.phase=STARTED`。
4. 升级前后的 `ai-suite-configmap.data` 完全一致；「Hello Halo」的文章 ID、标题和原有标签引用一致。新版「AI 标签」页面可加载该文章及「Halo」标签。

## 范围与发布前事项

本轮未配置真实模型，因此没有再次发起标签生成、摘要、写作或索引调用；也没有覆盖生产站点的数据库类型、历史索引或第三方主题组合。发布前应以最终发布 JAR 重核 SHA-256，并按生产环境的备份、回滚和模型连通性流程执行上线检查。
