# AI 宠物皮肤合成流程

国内图像编辑模型可以只提供参考图和自然语言指令，不要求模型 API 支持 mask。模型输出作为候选表情帧，本地合成工具通过项目维护的 mask 锁定母版轮廓、透明通道和非表情区域。

## 输入约定

- `master`：已验收的透明 PNG 待机母版，也是所有状态的轮廓和 Alpha 来源。
- `mask`：与母版等尺寸的灰度 PNG。黑色区域完全保留母版，白色区域采用模型输出，灰色区域用于柔化边缘。
- `sources`：模型生成的 `blink`、`happy`、`sad`、`thinking` 候选图。每张图片必须与母版尺寸一致。
- 配置文件格式参考 `scripts/pet-skin-compose.example.json`。

固定皮肤应人工绘制并复核 mask。猫咪通常覆盖眼睛、眉毛、嘴巴和少量脸颊；机器人只覆盖屏幕；精灵覆盖五官和必要的局部光效。mask 不应接触角色外轮廓。

## 执行

项目开发环境已使用 Pillow 处理皮肤素材：

```bash
python3 scripts/pet-skin-compose.py output/cream-cat-skin/pipeline.json
```

工具生成五张 384×384 PNG、包含 384px 与 96px 深浅背景效果的评审图，以及 JSON 质检报告。以下条件不满足时命令直接失败：

- mask 或模型输出尺寸与母版不一致；
- mask 为空或覆盖整张图片；
- mask 外出现像素变化；
- 任意状态的 Alpha 轮廓与母版不一致。

质检通过后仍需人工检查 96px 实际尺寸下的表情辨识度、接缝、色差和五官位置。发布资源前运行完整 Gradle 构建，确认五种状态均被插件打包。

## 模型提示词

每个状态均使用同一张母版作为参考图，并明确要求保持画布尺寸、构图、身体姿态、轮廓、毛发、光线和背景不变，只改变目标表情。模型即使修改了其他区域，本地合成也会丢弃 mask 外的变化。

## 在线复古像素流程

新的 pixel 母版统一为96网格、最多24色及二值透明度，以4倍最近邻保存384PNG；背景审核仍然必需。pixelGridSize=96标记新流程。表情模型参考单独放大至1024，候选必须是1024方图；本地合成降至96网格，只使用母版色板，硬边区域与母版透明度锁定。背景清理也按网格重新二值化。

后台预览和前台manifest采用imageRendering=pixelated。推荐96px展示，非整数缩放可能像素块不均。历史pixel缺少标记时保留旧图片和合成路径，重做母版后才启用；精致立体及内置皮肤不变。旧附件生命周期不在本轮修改范围。
