# 0.4.2 Release Notes

## 新增

- **AI 标签**：在独立页面为草稿或已发布文章生成候选标签，选择后再应用；优先复用已有标签，保留文章原有标签。Halo 文章列表的操作菜单也可直接打开生成弹窗。
- **内容创作模型分配**：可设置内容创作默认语言模型，AI 摘要、AI 标签和写作辅助也可分别指定模型。留空时依次回退到内容创作默认模型、对话模型、AI Foundation 默认语言模型。
- **用量记录**：标签生成单独计入 `tag_generate` 场景；应用候选标签本身不调用模型。

## 兼容性与升级

- 要求 Halo `2.26.0` 或更高版本、Halo AI Foundation `1.1.1` 或更高版本，以及 Java 21。
- 从 0.4.1 升级无需迁移现有配置或重建文章索引。升级前备份 Halo 数据、AI 智能套件 ConfigMap、AI Foundation 配置和旧 JAR；升级后确认插件状态为 `STARTED`，并复核模型配置、文章标签与内容创作入口。
- 更换 Embedding 模型或向量维度时，仍需全量重建索引。回滚步骤见[升级与迁移](../../docs/operations/upgrade-and-migration.md)。

## 验证与限制

- 本地 JDK 21 完整构建通过，183 项 Java 测试和前端检查通过；Halo 2.26.1 上的全新安装及正式 0.4.1 JAR 升级验收通过。
- AI 标签生成、选择和应用已在本地测试文章上验证。生产环境的数据库、主题、代理链路和模型供应商配置应按各站点实际条件复核。
